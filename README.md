# CZECHENDURO – statický web pro GitHub Pages

1. Na GitHubu vytvořte nový repozitář (např. `czechenduro`).
2. Nahrajte do něj **obsah** této složky (soubor index.html musí být v kořeni repozitáře, ne ve podsložce).
3. V repozitáři otevřete **Settings → Pages**, u „Source“ zvolte **Deploy from a branch**, větev **main** a složku **/ (root)**, uložte.
4. Za 1–2 minuty bude web na adrese https://VASE-JMENO.github.io/czechenduro/

Web funguje v kořeni domény i v podsložce, odkazy jsou relativní. Fotky se načítají z framerusercontent.com (současný web).
Vygenerováno příkazem `npm run export:pages` z projektu czechenduro-web.
